# Buki app

Frontend React + Vite + TypeScript. La Fase 1 deja un arranque mínimo con modo
`mock`; la experiencia móvil y el plan simulado se construyen en la Fase 2.

## Desarrollo local

```powershell
npm install
npm run dev
```

La configuración opcional vive en `.env` y parte de `.env.example`:

```text
VITE_BUKI_MODE=mock
VITE_BUKI_API_URL=http://127.0.0.1:8000
```
